## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/butterchicken31/arjun-portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd arjun-portfolio
   ```

3. Open `index.html` in your browser, or use the Live Server extension in VS Code.
